# Sources

This directory is reserved for raw source files, extracted intermediates, and manifest files that drive ingestion.

- `raw/`: archived upstream files with versioned paths and checksums
- `extracted/`: parser intermediates when a source needs a reviewed extraction step
- `manifests/official/`: ingestable checked-in source manifests
- `manifests/planning/`: planning catalogs for backlog sensors
- `manifests/templates/`: starter manifests for new sources
